# Мой Город — Web / PWA

Веб-версия приложения «Мой Город», которую можно установить на iPhone из Safari как обычное приложение (Add to Home Screen).

## Как установить на iPhone

1. Откройте сайт в **Safari** (не в Chrome / Telegram и т.д.)
2. Нажмите кнопку **Поделиться** (квадрат со стрелкой вверх)
3. Пролистайте и выберите **«На экран «Домой»»**
4. Нажмите **Добавить**

Иконка «Мой Город» появится на домашнем экране. Приложение откроется без адресной строки Safari (режим standalone).

## Что уже есть

- Главный экран с городом, местами и событиями
- Раздел «Город» с сеткой сервисов (ЖКХ, клиники, транспорт и др.)
- Новости, карта, профиль
- Выбор города, темы
- PWA: manifest, service worker, иконки, Apple meta-теги
